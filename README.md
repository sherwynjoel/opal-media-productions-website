# OPAL - Media Production & Digital Marketing Website

A complete, modern, professional website for a Media Production & Digital Marketing company.

## 🎨 Design Features

- **Premium Color Scheme**: Deep navy (#1a1a2e) with gold accents (#d4af37) and teal highlights (#00d4aa)
- **Typography**: Inter (body) and Playfair Display (headings) for a modern, elegant look
- **Fully Responsive**: Mobile-first design that works on all devices
- **Modern UI/UX**: Clean layouts, smooth animations, and intuitive navigation

## 📁 Website Structure

### Pages
- **index.html** - Homepage with hero section, services overview, and CTAs
- **about.html** - About page with company story, values, and mission
- **services.html** - Comprehensive services page covering all offerings
- **portfolio.html** - Portfolio gallery with filtering capabilities
- **contact.html** - Contact page with form and contact information

### Assets
- **styles.css** - Complete stylesheet with premium design system
- **script.js** - Interactive features including mobile menu, portfolio filter, form validation

## 🚀 Getting Started

1. Open `index.html` in your web browser
2. All pages are linked and ready to use
3. Customize content, images, and contact information as needed

## 🔧 Customization

### Update Contact Information
Edit contact details in:
- All HTML files (footer sections)
- `contact.html` (contact info section)

### Add Portfolio Images
Replace portfolio placeholders in `portfolio.html`:
- Add actual images/videos
- Update portfolio items with real project data

### Backend Integration
The contact form in `script.js` includes commented code for backend integration. Uncomment and configure the fetch API call to connect to your server.
